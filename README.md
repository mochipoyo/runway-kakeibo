# 生活ランウェイ家計簿

個人と法人の資産、毎月の支出（サブスク・光熱費など）と収入を入力すると、「あと何か月生活できるか」を計算し、効果の大きい見直し先を提案するブラウザアプリです。

## できること

- 個人・法人それぞれの資産、支出、収入の入力（年払いは月額に換算）
- 残り月数の表示（合算／個人だけ／法人だけ／現金・預金だけ）と残高の推移グラフ
- 改善アドバイス（重複サブスク、1項目をやめた場合に延びる期間のランキングなど）
- 支出削減・収入増のシミュレーター
- 「税・社保」タブ：自治体（都道府県）・社会保険の加入形態・扶養家族・年齢を選び、役員報酬の額面から所得税・住民税・社会保険料と、法人の税金を概算
- 役員報酬を変えた場合の比較表

## データの保存について

入力したデータは、使っているブラウザの localStorage にだけ保存されます。サーバーへの送信は一切ありません。別の端末へ移すときは、画面右上の「バックアップ」から文字列をコピーして使ってください。

## 注意

- 計算はすべて**概算**です。端数処理・国保の軽減・配偶者特別控除・特定親族特別控除・賞与・繰越欠損金などは簡略化または省略しています。
- 住民税は標準税率（所得割10%）、法人の地方税は標準税率で計算しています。自治体によっては超過課税があります。
- 税率・保険料率は毎年度変わります。年度が変わったらコード内の数値（`PREF`、`KAIGO`、`KOSODATE`、`KOKUNEN`、`KK_OSAKA`、`kisoIT` など）を更新してください。
- 申告や役員報酬の決定には使わず、税理士などの専門家に確認してください。

## 公開方法（GitHub Pages）

1. GitHub で新しいリポジトリを作る（例：`runway-kakeibo`、Public）
2. `index.html` と `README.md` をアップロード
3. Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/runway-kakeibo/` で公開されます

更新するときは、新しい `index.html` を同じ名前で上書きアップロードするだけです。
